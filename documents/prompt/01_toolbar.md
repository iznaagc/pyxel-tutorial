# マップチップ描画について修正したいことや要望

## 要望

### 機能について

- Toolに消しゴム機能が欲しい
    - マップチップを描画するモードと消去モードを切り替えらえるようにしたい
    - RectもBucketも描画と消去モードを基に機能するようにしたい
        - 例
            - 描画モード
                - いまの状態で問題無し
            - 消去モード
                - Pen
                    - 選択したマスに描画されているチップを消す
                - Rect
                    - ドラッグで選択した範囲のチップを消す
                - Bucket
                    - 選択したチップと隣接している同一のチップだけを対象に消す

### UIについて

- マップチップペイントツールについて
    - 現状テキスト名のボタンで切り替えているが、今後もツールは増えていくのでペイントツールみたいにアイコンボタンにしてわかりやすくしたい
    - アイコンボタン一覧は画面の右端に縦に並べたい
