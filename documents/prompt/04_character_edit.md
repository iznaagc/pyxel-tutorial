# キャラクターエディットモードの追加

- GUIに新たなモードとしてキャラクターエディット機能を作りたい

## 概要
- 個々のキャラクターの設定が出来るようになる

### 必要な機能

- キャラクター名設定
	- 文字列
- 初期職業設定
	- 数値
	- ジョブIDで紐づき
- グラフィック設定
	- 顔グラフィック
		- 画像のID
	- 歩行グラフィック
		- 画像のID
	- 戦闘グラフィック
		- 画像のID
- 性格
	- 数値
	- 性格IDで紐づき
- 基礎ステータス設定
	- 各種
		- 数値
	- 要素
		- HP
		- MP
		- STR
		- VIT
		- INT
		- MND
		- LUK
- 成長率
	- 各種
		- 数値
	- 能力
		- HP
		- MP
		- STR
		- VIT
		- INT
		- MND
		- LUK
	- スキル
		- 物理
			- 短剣
			- 剣
			- 刀
			- 斧
			- 槍
			- 棍
			- 爪
			- 弓
		- 魔術
			- 回復
			- 元素
			- 強化
			- 弱体


### 画像表示の仕様
- 基本的な仕様
	- 選択した画像IDの左上から指定された範囲のグラフィックを描画する
	- 例
		- 切り取り範囲
		- 32x32
		- キャラ1つ目
			- 顔グラフィック
				- 画像ID
					- 123
				- 選択ID
					- 0
				- 実際に描画される画像の座標
					- X0, x31
					- y0, y31
		- キャラ2つ目
			- 顔グラフィック
				- 画像ID
					- 123
				- 選択ID
					- 1
				- 実際に描画される画像の座標
					- X32, x63
					- y0, y31
