# ツールバーの選択範囲機能の修正とショートカットの追加

## 要望

### 機能について

- 選択範囲の修正
    - 現状選択範囲で指定の区域を選択すると、選択した者とは別に背景の色が変わっているのでそれを無くしてほしい。
    - 実際に選択した矩形のみフォーカスをしたい
    - 選択範囲で選択している最中に他のツールに切り替えたら選択範囲は解除してほしい
    - 選択している範囲はDeleteキーを押すと消去できるようにしたい
- ショートカットの追加
    - ペンツール
        - Bキー
    - 矩形ツール
        - Rキー
    - 消しゴムツール
        - Eキー
    - 選択範囲
        - Sキー
    - バケツツール
        - Fキー
