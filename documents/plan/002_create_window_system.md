# 実現したいこと

- キャラクターが会話するときに表示するメッセージウィンドウシステムの作成

## ルール

- Pyxelの機能を使えるなら優先してそれを使用して作成すること
- PyxelのSkillsを使用すること


## 現状と調査してほしいこと

tutorial\src\ui\window.py に汎用オーバーレイウィンドウクラスがある。

それ以外でウィンドウを制御している部分があれば調査してほしい。

## ウィンドウシステム作成の方向性

ウィンドウに共通している機能は汎用クラスに持たせて、メッセージウィンドウに特化した機能はメッセージウィンドウクラスに持たせる
オーバーレイウィンドウも汎用クラスをベースとして専用の子クラスにする

## 要件

- ウィンドウ描画機能
    - x,y,w,hで表示位置とサイズを指定できるようにする
    - よく使うサイズは定数で定義できるようにする(メッセージウィンドウ等)
    - 渡された情報にキャラクターの名前情報があればウィンドウの左上に別のウィンドウを出して名前表示枠を描画
    - メッセージウィンドウの文章は最大3行表示
    - 顔グラフィックが存在する文章であれば顔グラフィックを左側に表示
    - ウィンドウ枠の有無を選択できるようにする
    - ウィンドウの背景を半透明にするか選択できるようにする
- メッセージ表示機能
    - 表示するメッセージを1文字ずつ表示する機能
        - ゲームオプションで表示速度を変更できるようにする
        - 1文字ずつ表示中は決定キーで即時表示完了できるようにする
    - メッセージがすべて表示されたらキー入力待ちにしてキーが押されたら次のメッセージを表示
        - メッセージ送りがある場合はメッセージ送りアイコンを簡単なアニメーション付きで表示
        - 次のメッセージが無い場合は、ウィンドウを閉じる
        - 状況に応じて自動送りする場合もあるのでそれを考慮した作りにすること
