# 要望

- 文章を下から上に流すテロップ機能を作りたい。
- 文字表示に関してはウィンドウベースクラスを流用できそうですが、必要な機能として、 

## テロップの用途

- オープニングシーンでストーリーの文章を表示する
- スタッフロールとして使う

## 要件定義

- ウィンドウベースクラスの文字表示機能を流用
    - ウィンドウの背景や枠を非表示にする機能を付ける
    - ウィンドウの位置を移動させる機能
    - 文字を動かすのではなくウィンドウごと動かす仕様にする
- 3行以上の文章を表示できるようにする

## 実装する前に考えること

- ウィンドウベースクラスに盛り込んでも問題ないか
