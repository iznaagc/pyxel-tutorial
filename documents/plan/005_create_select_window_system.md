# 要望

- ウィンドウのベースから派生して選択肢ウィンドウクラスを作る

## 選択肢ウィンドウの用途

- はい・いいえ等のプレイヤーが選択するために表示するウィンドウ
- メニュー画面の項目選択

## 要件定義

- 選択肢の内容を辞書などで管理する
- 選択肢のカーソル移動
	- カーソル移動の長押しの挙動
		- カッ……カカカカ...みたいな動きにしたい
        - 10フレーム待機してから移動開始
        - その後5フレームごとに移動など定数で調整できるようにしておく
	- 一番上か一番下にいるときに順方向に押したらカーソルがループする
- 選択した位置の情報を保持
	- 選んだ位置を数値で管理
- キャンセルボタン時の処理
	- ボタン押下時に選ばれる位置を決められるようにする

## 既存機能の改修

- もしまだ達成できていないなら以下の改修を行う
    - 今後別のウィンドウシステムも派生して作るのでメッセージウィンドウのテキスト表示機能自体はベース側に映す
    - メッセージウィンドウはメッセージ表示に特化させる
    - テキストの内容に合わせてウィンドウ枠を拡張するかどうかを選べるようにする
        - メッセージウィンドウ側は固定のため拡張しないでいいので、フラグで拡張しないようにする
        - デフォルトは拡張するようにする
