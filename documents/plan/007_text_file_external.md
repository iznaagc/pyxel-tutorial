# 要望

- テキストファイルの外部ファイル化
- ゲームとは別にテキストを管理するエディタをpyxel作りたい
- プロジェクトルートにtoolsディレクトリを作ってそこにエディタを置く
- エディタはそのうちイベントやマップ、スプライトを管理したりするゲーム制作エディタにもしたいので拡張性を考慮すること
- ひとまずはテキストを管理するエディタを作りたい
- 入力したテキストは実際のゲームでみられるようにプレビューできる機能が欲しい

## どうやって管理するべきなのかを考える

- キャラクターの文章やテロップの内容などは外部ファイルとして管理して後から変更しやすいようにしたい
- ステータスの能力値の名称(STRやらINTやら)は定数などでソースコード側で管理する

## 要件定義

- テキストはUTF-8で保存する
- 最終的な出力はバイナリファイルにする
- ゲーム側はバイナリを読み込んでゲーム内で復元して文章を使えるようにする

## 実装する前に考えること

- このやり方で問題ないかを検討する
- ファイル管理方法の最適なやり方があればそれを提案してください
