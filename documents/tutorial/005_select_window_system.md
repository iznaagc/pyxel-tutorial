# 005: 選択肢ウィンドウシステム

## 概要

プレイヤーに選択肢を提示して選ばせる **SelectWindow** を実装した。
BaseWindow のリファクタリング（テキスト表示共通化・アクティブ状態管理）を行い、
メッセージウィンドウと選択肢ウィンドウが同時に画面上に存在するケースにも対応した。

---

## 背景・目的

- RPGの会話分岐やメニュー操作に「選択肢ウィンドウ」が必要
- メッセージウィンドウと選択肢ウィンドウが同時に表示されるとき、どちらが操作可能かを視覚的に区別したい
- メニュー項目が多い場合にスクロールやページ送りで対応したい
- デモシーンが長大になったため、テスト項目を個別に選んで実行できるメニュー方式にしたい

---

## クラス構成

```
BaseWindow（基底クラス）
├── OverlayWindow（汎用オーバーレイ）
├── MessageWindow（メッセージ表示専用）
└── SelectWindow（選択肢ウィンドウ）  ← 新規
```

## BaseWindow の拡張

### アクティブ / 非アクティブ状態

複数ウィンドウが同時に表示されるとき、どのウィンドウが入力を受け付けているかをプレイヤーに示す仕組み。

```python
# アクティブ: 白枠（border_color=7）
window.activate()

# 非アクティブ: 灰枠（INACTIVE_BORDER_COLOR=13）
window.deactivate()
```

| 状態 | 枠線色 | 入力受付 |
|------|--------|----------|
| アクティブ | `border_color`（デフォルト白=7） | あり |
| 非アクティブ | `INACTIVE_BORDER_COLOR`（灰=13） | なし |

**実装のポイント:**
- `_current_border_color()` メソッドで状態に応じた枠線色を返す
- `close()` 時に自動で `deactivate()` される
- MessageWindow・SelectWindow の `update()` は `is_active` が False なら何もしない

### テキスト表示の共通化

BaseWindow にテキスト行の管理・描画メソッドを追加し、サブクラスで共通利用できるようにした。

```python
# 共通定数
DEFAULT_TEXT_PADDING = 8
DEFAULT_LINE_HEIGHT = 20

# 共通メソッド
window.set_lines(["行1", "行2"])    # テキスト設定（auto_resizeなら自動リサイズ）
window._draw_text_lines()            # テキスト描画
window._resize_to_fit()              # テキストに合わせてサイズ調整
```

### auto_resize フラグ

| クラス | auto_resize | 理由 |
|--------|-------------|------|
| OverlayWindow | False | 固定サイズで使用 |
| MessageWindow | False | 定数でサイズ固定 |
| SelectWindow | True | 選択肢の内容に合わせて自動調整 |

## SelectWindow

### 基本的な使い方

```python
from ui.select_window import SelectWindow

# はい/いいえの2択
sw = SelectWindow(
    x=200, y=60,
    items=["はい", "いいえ"],
    cancel_index=1,        # ESCで「いいえ」が選ばれる
)
sw.open()
sw.activate()
```

### コンストラクタのパラメータ

| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `x, y` | int | - | ウィンドウ左上の座標 |
| `items` | list | - | 選択肢のリスト（str または dict） |
| `width, height` | int | 0 | サイズ（auto_resize=True なら自動計算） |
| `confirm_key` | int | KEY_RETURN | 決定キー |
| `cancel_key` | int | KEY_ESCAPE | キャンセルキー |
| `cancel_index` | int | -1 | キャンセル時に返すインデックス（-1で無効） |
| `initial_cursor` | int | 0 | 初期カーソル位置 |
| `max_visible` | int | 0 | スクロール表示上限（0=制限なし） |
| `page_size` | int | 0 | ページ送りの1ページ項目数（0=なし） |
| `semi_transparent` | bool | False | 背景半透明 |

### update() の戻り値

```python
result = sw.update()

if result is not None:
    # result = 選択されたアイテムの元インデックス（int）
    print(f"選択: {result}")
else:
    # まだ選択されていない
    pass
```

### 選択肢の形式

```python
# 文字列のリスト
items = ["攻撃", "魔法", "逃げる"]

# dict のリスト（label キーを使用）
items = [
    {"label": "攻撃", "damage": 10},
    {"label": "魔法", "mp_cost": 5},
    {"label": "逃げる"},
]
```

### 操作方法

| キー | 動作 |
|------|------|
| ↑ / ↓ | カーソル移動（ループ、長押しリピート対応） |
| Enter / Space | 決定 |
| ESC | キャンセル（cancel_index が設定されている場合） |

### カーソルの長押しリピート

`pyxel.btnp(key, hold, repeat)` を使い、長押し時のカーソル自動移動を実現。

```python
REPEAT_INITIAL_WAIT = 10   # 長押し開始までの待機（10フレーム）
REPEAT_INTERVAL = 5        # リピート間隔（5フレーム）

# pyxel.btnp の hold/repeat 引数で自動対応
pyxel.btnp(pyxel.KEY_UP, REPEAT_INITIAL_WAIT, REPEAT_INTERVAL)
```

- 最初の10フレーム: キーを押し続けても1回だけ反応
- 10フレーム以降: 5フレームごとにリピート発火
- 項目数が多いリストでもストレスなく操作できる

### 自動リサイズ

`auto_resize=True`（デフォルト）のとき、選択肢テキストの最大幅と項目数からウィンドウサイズを自動計算する。

```
幅 = カーソル文字幅 + 最長テキスト幅 + パディング×2
高さ = 表示行数 × 行高さ + パディング×2
```

`config.FONT.text_width()` で日本語・英語混在テキストの実際の描画幅を正確に算出。

## スクロール機能（max_visible）

項目数が多い場合に、表示上限を設けてカーソル追従でスクロールする機能。

```python
sw = SelectWindow(
    x=160, y=20,
    items=["アイテム1", "アイテム2", ..., "アイテム8"],
    max_visible=5,   # 5項目まで表示、残りはスクロール
)
```

### 動作仕様

- カーソルが表示範囲の外に出ると自動的にスクロールオフセットが調整される
- 上下に続きがある場合は `...` インジケータ（色13=灰）で表示
- カーソルは全項目間でループする（末尾→先頭、先頭→末尾）

### 描画構造

```
┌──────────────────┐
│    ...            │  ← 上にスクロール可能（灰色）
│  > アイテム3      │  ← カーソル位置
│    アイテム4      │
│    アイテム5      │
│    ...            │  ← 下にスクロール可能（灰色）
└──────────────────┘
```

ウィンドウの高さはスクロールインジケータ（各10px）の分だけ加算される。

## ページ送り機能（page_size）

項目をページ単位で分割し、ナビゲーション項目で明示的にページを切り替える機能。

```python
sw = SelectWindow(
    x=16, y=36,
    items=["項目A", "項目B", ..., "項目J"],  # 10項目
    page_size=8,    # 1ページ8項目
)
```

### スクロールとの違い

| 特徴 | スクロール (max_visible) | ページ送り (page_size) |
|------|--------------------------|------------------------|
| 切り替え方法 | カーソル移動で自動 | ナビ項目を決定キーで選択 |
| 表示内容 | 連続的にスライド | ページ単位で切り替え |
| 操作感 | スムーズ | 明確な区切り |
| 用途 | アイテムリスト等 | メニュー、カテゴリ分け等 |

### 動作仕様

- 項目がページに分割され、各ページに最大 `page_size` 個の実アイテムが表示される
- 次ページがある場合は末尾に **「次のページへ >」**（黄色）が表示される
- 前ページがある場合は先頭に **「< 前のページへ」**（黄色）が表示される
- ナビ項目を決定すると閉じずにページが切り替わる
- 実アイテムを決定すると元のインデックスを返してウィンドウを閉じる
- 右下に **ページインジケータ**（例: `1/2`、灰色）が表示される

### ページ表示の構造

```
ページ1/2:                        ページ2/2:
┌──────────────────────┐          ┌──────────────────────┐
│ > 項目A              │          │   < 前のページへ      │  ← 黄色
│   項目B              │          │ > 項目I              │
│   項目C              │          │   項目J              │
│   項目D              │          │                      │
│   項目E              │          │                      │
│   項目F              │          │                      │
│   項目G              │          │                      │
│   項目H              │          │                      │
│   次のページへ >     │  ← 黄色  │                      │
│                 1/2  │          │                 2/2  │
└──────────────────────┘          └──────────────────────┘
```

### ウィンドウサイズの計算

ページ送りモードでは、最大表示行数に基づいてウィンドウの高さを固定する。

```
最大表示行数 = page_size + ナビ項目数
ナビ項目数 = min(2, 総ページ数 - 1)
  - 2ページ → ナビ1個（次 or 前）
  - 3ページ以上 → ナビ2個（前 + 次）

高さ = 最大表示行数 × 行高さ + パディング×2
```

幅はナビ項目のラベルも含めた全テキストの最大幅から計算される。

### ページ切り替え時のカーソル位置

| 操作 | カーソルの移動先 |
|------|------------------|
| 「次のページへ >」決定 | 次ページの最初の実アイテム |
| 「< 前のページへ」決定 | 前ページの最後の実アイテム |
| `open(initial_cursor=N)` | N番目のアイテムがあるページのそのアイテム |

## デモシーンのメニュー化

### 変更前

テストパターンが順番に流れる長いデモ → 全部見るのに時間がかかる。

### 変更後

SelectWindow を使ったメニューから個別にテスト項目を選択して実行。

```python
DEMO_MENU_ITEMS = [
    "メッセージ：基本（日本語会話）",
    "メッセージ：文字数テスト",
    "メッセージ：日英混在/名前/自動送り",
    "選択肢：はい/いいえ",
    "選択肢：3択メニュー",
    "選択肢：長いテキスト（自動リサイズ）",
    "選択肢：多数選択肢（長押しリピート）",
    "選択肢：半透明ウィンドウ",
    "ウィンドウ：アクティブ/非アクティブ",
    "タイトルに戻る",
]

DEMO_MENU_MAX_VISIBLE = 8  # ページ送りで表示

self._demo_menu = SelectWindow(
    x=16, y=36,
    items=DEMO_MENU_ITEMS,
    cancel_index=len(DEMO_MENU_ITEMS) - 1,
    page_size=DEMO_MENU_MAX_VISIBLE,
)
```

### 状態管理

```python
STATE_MENU = 0           # メニュー表示中
STATE_MSG_DEMO = 1       # メッセージウィンドウデモ中
STATE_SELECT_DEMO = 2    # 選択肢ウィンドウデモ中
STATE_ACTIVE_DEMO = 3    # アクティブ/非アクティブデモ中
```

### キー操作

| キー | 状態 | 動作 |
|------|------|------|
| ↑↓ Enter Space ESC | メニュー | メニュー操作 |
| Enter / Space | デモ中 | ウィンドウ操作 |
| Backspace | デモ中 | メニューに戻る |
| Q | いつでも | タイトルに戻る |
| TAB | アクティブデモ中 | アクティブウィンドウ切り替え |

**ESCキーの分離:**
ESCはウィンドウのキャンセル操作（cancel_key）専用とし、シーン遷移にはBackspaceとQを使用する。
これにより、選択肢ウィンドウでESCキャンセルを使った直後に意図せずシーンが変わる問題を回避。

### アクティブ/非アクティブデモ

TABキーで2つのウィンドウ（選択肢 + メッセージ）のアクティブ状態を切り替えるデモ。
白枠のウィンドウだけが入力を受け付け、灰枠のウィンドウは表示のみであることを視覚的に確認できる。

## スクリーンショット撮影ハーネス

UIの表示結果を自動でスクリーンショット保存する仕組み。
Pyxelには入力シミュレーションAPIがないため、UIコンポーネントを直接操作して目的の表示状態を作る。

### 仕組み

```
フレーム N（draw）:  UIコンポーネントを構築 → 描画
フレーム N+1（update）: pyxel.pget() で画面バッファ読み取り → PNG保存
```

1. `draw()` でUIを構築・描画（phase=0）
2. 次の `update()` で `pyxel.pget()` を使い全ピクセルを読み取り（phase=1）
3. Pyxelパレットインデックス → RGB変換して Pillow で2倍スケールPNGに保存

### 使い方

```bash
cd src && ../.venv/Scripts/python test_harness.py
```

撮影対象の追加方法は CLAUDE.md に記載。

## 注意点・ハマりどころ

### max_visible と page_size は排他的に使う

両方同時に指定した場合は `page_size` が優先される（`_has_scroll` が False になる）。
用途に応じてどちらか一方を選択する。

### ページ送りのカーソルは表示内のローカル位置

ページ送りモードでは `_page_cursor` がページ表示内の位置を指す。
`cursor` プロパティは元のアイテムインデックスに変換して返すため、
`open(initial_cursor=self._demo_menu.cursor)` でメニュー復帰時にページ・位置が復元される。

### ESCキーの役割を明確に分ける

ウィンドウの `cancel_key`（ESC）とシーン遷移のキーが同じだと、
キャンセル操作が意図せずシーン遷移を引き起こす。
シーン遷移には別のキー（Q、Backspace等）を使い、ESCはウィンドウ操作専用にする。

### activate / deactivate は必ずペアで管理する

複数ウィンドウを扱う場合は、一方を activate する際に他を deactivate する
ヘルパーメソッド（`_activate_window()`）を用意すると、
アクティブ状態の管理漏れを防げる。

```python
def _activate_window(self, window):
    """指定ウィンドウをアクティブにし、他を非アクティブにする。"""
    self._demo_menu.deactivate()
    self.msg_window.deactivate()
    if self._select_window:
        self._select_window.deactivate()
    window.activate()
```
