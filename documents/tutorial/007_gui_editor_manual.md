# GUIエディタ操作説明書

## 1. 概要

このドキュメントは、`tools/gui_editor.py` で実装されている GUI エディタの現状仕様を、人間が手動レビューできるようにまとめた操作説明書です。

エディタは 3 つのモードを持ちます。

- `Text Editor`: メッセージ、選択肢、テロップ、イベント定義の編集
- `Map Editor`: タイルマップの作成・編集
- `Character Editor`: キャラクターのステータス・グラフィック・成長率の編集

同じアプリ内で `Mode` メニューから切り替えて使います。3 モードとも実装済みです。

---

## 2. 起動方法

プロジェクトルートで以下を実行します。

```powershell
.venv\Scripts\python tools\gui_editor.py
```

初回確認時の前提ディレクトリ:

- テキストデータ: `data/text/`
- マップデータ: `data/maps/`
- タイルセット画像: `assets/tilesets/`

---

## 3. 画面構成

### 3.1 Text Editor モード

画面は概ね以下の 3 ペイン構成です。

1. 左: ファイルツリー
2. 中央: 編集フォーム
3. 右: プレビュー

編集対象:

- `Messages`
- `Selections`
- `Telops`
- `Events`

### 3.2 Map Editor モード

画面構成:

1. 左: マップ一覧ツリー
2. 中央: マップキャンバス
3. 右: サイドパネル

右サイドパネルの内容:

- タイルセットパレット
- ミニマップ
- レイヤーパネル
- マッププロパティ

---

## 4. 共通操作

### 4.1 モード切り替え

メニュー:

- `Mode > Text Editor`
- `Mode > Character Editor`
- `Mode > Map Editor`

3 モードとも切り替え可能です。

### 4.2 共通ショートカット

| 操作 | キー |
|---|---|
| 保存 | `Ctrl+S` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |
| コンパイル | `F5` |
| リロード | `F9` |
| 検索バー表示 | `Ctrl+F` |
| 終了 | `Ctrl+Q` |

補足:

- `Ctrl+S` は現在モードに応じて保存対象が変わります
- Text Editor モードではテキスト JSON 群を保存します
- Character Editor モードでは character JSON 群を保存します
- Map Editor モードではマップ JSON を保存します
- `F5` は text + characters のコンパイルを実行します

---

## 5. Text Editor モード

### 5.1 編集対象

`data/text/*.json` を読み込み、ツリー上でカテゴリごとに表示します。

カテゴリ:

- `Messages`
- `Selections`
- `Telops`
- `Events`

### 5.2 基本操作

1. 左ツリーから対象ファイル内のエントリを選択
2. 中央フォームで内容を編集
3. 右プレビューで表示を確認
4. `Ctrl+S` で保存
5. 必要なら `F5` でコンパイル

### 5.3 補助操作

| 操作 | 方法 |
|---|---|
| ID追加 | `Edit > Add ID...` |
| IDリネーム | `Edit > Rename ID...` または `F2` |
| ID削除 | `Edit > Delete ID` または `Delete` |
| 未使用ID検出 | `Tools > Find Unused IDs...` |
| 検索 | `Ctrl+F` |

### 5.4 プレビュー

右ペインにはゲーム画面風のプレビューが表示されます。  
カテゴリごとの見た目確認に使えますが、実ゲームと完全一致の保証をするものではなく、レビュー支援用の描画です。

---

## 6. Map Editor モード

### 6.1 マップファイル

マップは `data/maps/*.json` から読み込みます。  
`Mode > Map Editor` へ切り替えると、左ツリーがマップ一覧表示になります。

新規作成:

- `Edit > New Map...`

新規作成時:

- 入力名は表示名にも使われます
- ファイル名は内部でサニタイズされます
- 保存先は `data/maps/`

### 6.2 マップ選択時に読み込まれるもの

マップを選ぶと以下が同期されます。

- キャンバス
- レイヤー一覧
- 通行判定 UI
- タイルセットプレビュー
- ミニマップ

タイルセットが未設定、または画像が見つからない場合はステータスバーに警告が出ます。

---

## 7. Map Editor の基本操作

### 7.1 キャンバス操作

| 操作 | 方法 |
|---|---|
| 描画 | 左クリック / 左ドラッグ |
| 消去 | 右クリック / 右ドラッグ |
| パン | 中クリックドラッグ |
| ズーム | マウスホイール |

ズーム範囲:

- `1x` から `8x`

### 7.2 ツールアイコンバー

キャンバス右端にアイコンの縦型ツールバーが表示されます。

| アイコン | キー | 内容 |
|---|---|---|
| Pen | `B` | 選択タイルを 1 マス単位で配置 |
| Rect | `R` | ドラッグ範囲を矩形塗り |
| Bucket | `F` | 連結領域をフラッドフィル |
| Select | `S` | 範囲選択（コピー＆ペースト用） |
| Eraser | `E` | 消去モードのトグル |
| Pass | `P` | 通行判定オーバーレイの表示切替 |

**消去モードについて**

- `E` キーまたはツールバーの Eraser ボタンで ON/OFF を切り替えます
- 消去モード ON 中は Pen・Rect・Bucket の全ツールが「タイル 0 で塗る」動作になります
- 消去モード ON 中でも右クリックドラッグによる一時消去は引き続き使えます
- Eraser ボタンが赤くハイライトされているとき消去モード中です
- Eraser はツール選択（Pen / Rect / Bucket / Select）とは独立したトグルです

**通行判定オーバーレイについて**

- `P` キーまたはツールバーの Pass ボタンで ON/OFF を切り替えます
- ON 中は通行不可タイルに赤い `×` が表示されます
- Pass ボタンがオレンジ色にハイライトされているとき表示中です

### 7.3 選択範囲の操作

`Select (S)` ツールで範囲を選択した後に使える操作:

| 操作 | 方法 |
|---|---|
| 範囲選択 | `S` に切り替えてドラッグ |
| コピー | `Ctrl+C` |
| 貼り付けモード開始 | `Ctrl+V` → クリックで確定、`Esc` でキャンセル |
| 選択範囲内を消去 | `Delete` |
| 選択範囲の解除 | 他のツール (`B` / `R` / `F` / `E`) に切り替え |

### 7.3 Undo / Redo 対応操作

現在 Undo / Redo できる代表操作:

- ペン描画
- 矩形塗り
- バケツ塗り
- コピー後の貼り付け
- マップサイズ変更
- レイヤー追加
- レイヤー削除
- レイヤー上下移動
- 通行判定変更
- イベント配置

## 8. タイルセットパレット

### 8.1 選択

右上のタイルセットパレットでタイルを選択します。

- 左クリック: 1 タイル選択
- 左ドラッグ: 矩形選択

矩形選択した場合、複数タイルをスタンプのように描画できます。

### 8.2 パレットズーム

タイルセットパレットは以下で拡大縮小できます。

- パレット上でマウスホイール
- `Map Properties` 内の `-` / `+` ボタン

### 8.3 補足表示

現在の実装では以下が確認できます。

- ホバー時のタイル番号と座標ツールチップ
- 選択タイルのプレビュー
- 選択範囲サイズ

---

## 9. 描画系機能

### 9.1 Pen

- 左ドラッグで連続配置
- 右ドラッグで連続消去
- 複数タイル選択中はブロック単位で配置

### 9.2 Rect

1. `R` で矩形ツールに切り替え
2. ドラッグ開始
3. ドラッグ中はプレビュー表示
4. マウスを離すと確定

### 9.3 Bucket

1. `B` でバケツツールに切り替え
2. 塗りたい場所をクリック
3. 同じタイル ID の連結領域を 4 方向で塗りつぶし

安全上限:

- 最大 `10000` タイル

上限到達時はステータスバーに警告が表示されます。

### 9.4 Select / Copy / Paste / Delete

選択ツール:

1. `S` で選択ツールに切り替え
2. キャンバスをドラッグして範囲選択

コピー:

- `Ctrl+C`

貼り付け:

1. `Ctrl+V`
2. 貼り付けプレビューが表示される
3. 左クリックで確定
4. `Esc` でキャンセル

範囲消去:

- 選択範囲を作成した状態で `Delete` キーを押すと、その範囲内のタイルがすべて空 (0) になります
- Undo (`Ctrl+Z`) で元に戻せます

選択範囲の解除:

- 他のツール (`B` / `R` / `F` / `E`) に切り替えると選択が自動解除されます

---

## 10. レイヤー機能

右サイドの `Layers` パネルで操作します。

### 10.1 できること

| 操作 | 方法 |
|---|---|
| アクティブレイヤー選択 | リスト内のレイヤーをクリック |
| レイヤー名の編集 | レイヤーをダブルクリック → 名前入力 |
| 表示 / 非表示切替 | Eye ボタン |
| レイヤー追加 | `+` ボタン |
| レイヤー削除 | `-` ボタン |
| レイヤー上移動 | `↑` ボタン |
| レイヤー下移動 | `↓` ボタン |

### 10.2 ルール

- 描画対象はアクティブレイヤーのみです
- 画面描画は下のレイヤーから順に重なります
- 非表示レイヤーは描画されません
- レイヤーは最低 1 枚残ります

### 10.3 レビュー時の確認ポイント

- レイヤー追加直後に新レイヤーが選択されるか
- 削除後にアクティブレイヤーが妥当な位置に移るか
- Undo / Redo 後もレイヤー表示と編集対象が一致しているか

---

## 11. ミニマップ

右サイドパネルに全体俯瞰のミニマップがあります。

できること:

- マップ全体の概形表示
- 現在の表示領域の確認
- クリック位置へのジャンプ

レビュー時は以下を確認してください。

- パン後にビューポート枠が更新されるか
- ズーム後にビューポート枠サイズが変わるか
- クリックジャンプでキャンバス中心が移るか

---

## 12. マッププロパティ

右サイド下部の `Map Properties` で編集します。

### 12.1 編集できる項目

| 項目 | 内容 |
|---|---|
| Name | マップ表示名 |
| Width / Height | マップサイズ（変更すると即座にリサイズ） |
| Tile Size | タイルのピクセルサイズ |
| Tileset | 使用タイルセット（ドロップダウンで選択） |
| Passability | 選択タイルの通行可否（Passable / Blocked） |

ツール切り替えボタンはキャンバス右上のアイコンバーに配置されています（セクション 7.2 参照）。

### 12.2 タイルセット変更

`Tileset` ドロップダウンから `assets/tilesets/` 内の PNG ファイルを選択します。マップ JSON にはファイル名が保存されます。

### 12.3 通行判定

`Passable` は現在選択中のタイルに対する設定です。

- `ON`: 通行可能
- `OFF`: 通行不可

通行不可タイルはキャンバス上に赤い `×` オーバーレイで表示されます。

---

## 13. マップ上のイベント配置

### 13.1 配置方法

イベントのないマスをダブルクリックすると、既存のイベント ID 一覧から配置対象を選べます。

配置元:

- `data/text/*.json` 内の `events` カテゴリ

### 13.2 既存イベントの編集

イベントが置かれているマスをダブルクリックすると、対応するイベント定義を Text Editor モードで開きます。

### 13.3 画面上の表示

イベントが配置されたマスには `E` バッジが表示されます。

### 13.4 レビュー時の確認ポイント

- 空マスのダブルクリックで配置ダイアログが出るか
- 配置後に `E` マークが出るか
- `Ctrl+Z` で配置を取り消せるか
- 既存イベントのダブルクリックで Text Editor の対象イベントへ移動できるか

## 14. データ形式

### 14.1 テキストデータ

テキストモードで扱う JSON は `data/text/*.json` にあります。  
カテゴリごとの詳細仕様は既存のテキスト系ドキュメントに従います。

### 14.2 マップデータ

マップ JSON の代表例:

```json
{
  "version": 1,
  "name": "DebugMap",
  "width": 20,
  "height": 15,
  "tile_size": 16,
  "tileset": "test_tileset.png",
  "passability": {
    "1": true,
    "2": false
  },
  "events": [
    {
      "x": 5,
      "y": 3,
      "event_id": "ev_chest_01"
    }
  ],
  "layers": [
    {
      "name": "ground",
      "visible": true,
      "tiles": [[0, 1, 1], [0, 2, 0]]
    }
  ]
}
```

主要フィールド:

| キー | 説明 |
|---|---|
| `name` | マップ名 |
| `width`, `height` | タイル数 |
| `tile_size` | 1 タイルのピクセルサイズ |
| `tileset` | `assets/tilesets/` 配下の画像ファイル名 |
| `passability` | タイルごとの通行可否 |
| `events` | 配置イベント一覧 |
| `layers` | レイヤー配列 |
| `layers[].tiles` | `[row][col]` の 2 次元タイル配列 |

タイル番号ルール:

- `0` は空タイル
- `1` 以上はタイルセット左上から行単位の 1-based index

## 15. 手動レビュー手順

最小レビューとして以下の順で確認すると、主要機能を一通り触れます。

### 15.1 Text Editor 確認

1. エディタを起動
2. `Text Editor` モードで任意の `messages` を開く
3. 文言を少し変更
4. プレビュー反映を確認
5. `Ctrl+Z` / `Ctrl+Y` を確認
6. `Ctrl+S` で保存

### 15.2 Map Editor 確認

1. `Mode > Map Editor`
2. `data/maps/DebugMap.json` を選択
3. タイルセットが表示されることを確認
4. キャンバス右端にアイコンツールバーが表示されることを確認
5. 1 タイル選択してペン描画 (Pen アイコンまたは `B`)
6. 右ドラッグで消去
7. `E` で消去モードをON → ペンで塗ってタイルが消えることを確認
8. `E` で消去モードをOFF に戻す
9. `R` で矩形塗り（描画モード）
10. `E` ON にして `R` で矩形消去
11. `F` でバケツ塗り（描画モード）
12. `E` ON にして `F` でバケツ消去
13. `S` で範囲選択し、選択中にマップ全体の背景色が変わらないことを確認
14. `Delete` キーで選択範囲内を消去、`Ctrl+Z` で元に戻ることを確認
15. `B` (Pen) に切り替えて選択範囲が解除されることを確認
16. `Ctrl+C` → `Ctrl+V` でコピー&ペースト
17. レイヤー追加、レイヤー移動、表示切替
18. `Passable` を切り替えて赤い `×` 表示を確認
19. 空きマスをダブルクリックしてイベント配置
20. `Ctrl+Z` / `Ctrl+Y` を複数回試す
21. ミニマップのクリックジャンプを確認
22. `Ctrl+S` で保存

---

## 16. 既知の注意点

現状の手動レビューでは、以下を前提に確認してください。

- コンパイルは主にテキストデータ向けです。マップレビュー時は保存を優先してください
- タイルサイズは新規作成後に変更できません
- イベント配置済みマスをダブルクリック → 「No」でイベント削除可能
- JSON を手動編集して同一座標に複数イベントを置いた場合、GUI 上では先頭の 1 件だけを扱います

## 17. Character Editor モード

### 17.1 概要

キャラクターの各種パラメータを編集するモードです。`Mode > Character Editor` で切り替えます。

データは `data/characters/*.json` に保存されます。

### 17.2 画面構成

- **左**: ファイルツリー（ファイル → Characters → キャラクターID）
- **中央**: キャラクター編集フォーム（スクロール可能）

### 17.3 編集項目

| セクション | フィールド | 説明 |
|-----------|-----------|------|
| 基本情報 | 名前 | キャラクター名（文字列） |
| 基本情報 | 初期職業 ID | ジョブIDで紐づき（整数） |
| 基本情報 | 性格 ID | 性格IDで紐づき（整数） |
| グラフィック | 顔 / 歩行 / 戦闘 | 画像ファイル名 + 選択ID（32x32切り出し） |
| 基礎ステータス | HP, MP, STR, VIT, INT, MND, LUK | 各ステータスの初期値（整数） |
| 成長率 - ステータス | HP, MP, STR, VIT, INT, MND, LUK | レベルアップ時の成長率（整数） |
| 成長率 - 物理スキル | 短剣, 剣, 刀, 斧, 槍, 棍, 爪, 弓 | 物理スキルの成長率（整数） |
| 成長率 - 魔術スキル | 回復, 元素, 強化, 弱体 | 魔術スキルの成長率（整数） |

### 17.4 グラフィックプレビュー

- `assets/images/sprite/` 内の PNG ファイルをドロップダウンで選択
- 選択ID は画像内の左端からの32x32切り出し位置（0始まり）
- 選択IDを変更すると右側にプレビューが表示される（2倍スケール）

### 17.5 操作

| 操作 | 方法 |
|------|------|
| キャラクターファイル追加 | Edit > New Character File... |
| キャラクター追加 | ツリーでファイルまたはカテゴリを選択し Edit > Add ID |
| キャラクター削除 | ツリーでエントリを選択し Delete キー |
| リネーム | ツリーでエントリを選択し F2 |
| 保存 | Ctrl+S |

### 17.6 データ形式

```json
{
  "version": 1,
  "file_id": "ファイル識別子",
  "characters": {
    "char_id": {
      "name": "キャラクター名",
      "initial_job": 0,
      "graphics": {
        "face": { "image": "filename.png", "selection_id": 0 },
        "walk": { "image": "filename.png", "selection_id": 0 },
        "battle": { "image": "filename.png", "selection_id": 0 }
      },
      "personality": 0,
      "base_stats": { "hp": 100, "mp": 20, "str": 10, "vit": 8, "int": 5, "mnd": 6, "luk": 7 },
      "growth_rates": {
        "stats": { "hp": 10, "mp": 5, "str": 3, "vit": 2, "int": 1, "mnd": 2, "luk": 2 },
        "physical_skills": { "dagger": 0, "sword": 3, "katana": 0, "axe": 0, "spear": 2, "staff": 0, "claw": 0, "bow": 0 },
        "magic_skills": { "healing": 0, "elemental": 1, "buff": 0, "debuff": 0 }
      }
    }
  }
}
```

### 17.7 コンパイル

`F5` または `Tools > Compile` でテキストデータと同時にコンパイルされます。
出力先: `data/compiled/characters_all.bin`（gzip 圧縮 JSON）
